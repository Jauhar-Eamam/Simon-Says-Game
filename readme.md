# 🎮 Simon Says Game

A classic memory-based game where the player has to remember and repeat an increasing pattern of colors.
This game is built using HTML, CSS, and JavaScript.

🚀 Features

✅ Simple and interactive UI
✅ Increasing difficulty (new color added each level)
✅ Sound feedback
✅ Game Over animation
✅ Responsive design

🛠️ Technologies Used

HTML – For structure

CSS – For styling and animations

JavaScript – For game logic and user interaction

🎯 How to Play

Press "Start" button (or any key).

A color will flash on the screen.

Click the colors in the same sequence.

Each level adds one more color to the pattern.

If you click the wrong color → Game Over
